## Changes

- A current naturally aggressive monster **already striking a selected farmer** now permits Warrior's native taunt even if the TTK risk gate correctly forbids voluntary boss combat. The taunt requires fresh live same-instance victim, native skill range, warrior >=70% HP, no other self-aggro, no PvP override, and rechecks at actual dispatch. No AoE, neutral pull, or unsafe boss hunt authority is granted.
- When out of native taunt range, the Warrior can make a single bounded <=65-unit physical intercept step, only toward a verified same-instance attacker already on another farmer. This still cannot guarantee survival without healer.
- Accessory discovery retains verified shop/stock/craft/route guards but prioritizes empty cape/earring slots, limits newly discovered vacant slots to base level 0, and does not create optimized goals for rotated-out farmers.
- Production acquisition quotes are filtered for finite positive evidence, non-speculative offers and bounded hours before selecting the best route.
- Merchant scheduling work is reduced by skipping offline character optimizer scans, avoiding expensive speculative accessory multi-level search. No financial authorization, user cap or durable ledger is relaxed.
